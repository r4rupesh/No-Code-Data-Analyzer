# 📊 No-Code Data Analyzer
## 🌐 Live Application
Access the deployed app directly in your browser:  
👉 **[No-Code Data Analyzer Live App](https://no-code-data-analyzer.streamlit.app/)**
A user-friendly, interactive Streamlit web application designed for non-technical users to clean, explore, analyze, and export raw data without writing a single line of code.

## ✨ Features

* **📥 Simple File Upload:** Support for drag-and-drop `.csv` and `.xlsx`/`.xls` files.
* **🧹 Automatic Data Cleaning:** Automatically strips whitespace from headers and removes duplicate records.
* **📋 Interactive Overview:** Highlights missing values, row/column counts, and data types automatically.
* **📈 Dynamic Visualizations:** Interactive Bar, Line, Scatter, and Histogram charts powered by Plotly.
* **🔍 Custom Filtering:** Easily filter numeric or categorical data using intuitive sliders and multi-select dropdowns.
* **📥 One-Click Export:** Download cleaned and filtered datasets as standard CSV files.
